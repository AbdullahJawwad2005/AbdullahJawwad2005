## What I Build

I like projects where code has to touch the real world: messy data, biological systems, human behavior, and AI workflows that need to be useful beyond a demo.

- **Computational biology:** behavioral analysis, mouse ethology, pose-estimation data, and biological research tooling
- **Machine learning:** classification pipelines, feature engineering, model evaluation, and applied data analysis
- **Agentic AI:** tool-augmented systems, reasoning frameworks, research workflows, and AI reliability
- **Full-stack apps:** React, TypeScript, Supabase, real-time interfaces, and AI-assisted user experiences
